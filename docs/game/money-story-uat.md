# Money Story — UAT contract

- Route: `/play/money-story/`
- One run represents 12 simulated months.
- All characters and financial values are fictional.
- Main systems: liquidity, investments, category-specific protection, borrowing and a character-specific goal.
- Financial pyramid is a small visual summary only; it is not the win condition.
- Sensitive events (serious health, loss, severe accident, unemployment hardship, disaster, family hardship) must not use joke copy or celebratory motion.
- Event selection uses eligibility and category-repeat dampening; no forced crisis is required.
- UAT must remain `noindex, nofollow, noarchive` and robots block-all under the existing Web UAT contract.
- LINE CTA sends no result code or game state.
- Analytics events must avoid raw financial state.
- Balance and 3–5 minute playtime are hypotheses until human playtesting.
